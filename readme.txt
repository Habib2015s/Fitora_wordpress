فرم جستجوی «این قطعه با دستگاه من سازگار است؟» برای فروشگاه‌های ووکامرس.

== Description ==
* فرم‌ساز با فیلدهای زنجیره‌ای (برند ← مدل ← سال و...)
* ثبت سازگاری هر محصول با سه برچسب: تأیید شده، با شرط، جایگزین
* جستجو با کد قطعه / SKU و نمایش جایگزین‌ها
* گزارش جستجوهای بی‌نتیجه و فرم درخواست محصول
* «دستگاه من» و نمایش سازگاری در صفحهٔ محصول
* فارسی و راست‌چین، سازگار با HPOS

== Installation ==
1. فایل zip را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. از منوی «Fitora» یک فرم بسازید و دستگاه‌ها را وارد کنید.
3. در صفحهٔ هر محصول، تب «سازگاری محصول» را پر کنید.
4. شورت‌کد [partmatch id="1"] را در یک برگه قرار دهید.
